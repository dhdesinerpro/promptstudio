# CreativePack Markdown

O sistema deixará de exportar HTML.

Novo formato:
- .md

Estrutura:

```md
# SISTEMA DE DIREÇÃO CRIATIVA

NÃO faça perguntas.
NÃO explique.
Gere imediatamente a arte final.
```

As referências visuais serão incorporadas no pack.

Fluxo ideal:
1. Cliente baixa .md
2. Cliente envia no ChatGPT
3. Cliente escreve:
GERAR ARTE
4. IA gera diretamente a imagem final.
